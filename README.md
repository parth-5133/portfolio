# Parth Patel - Full Stack Developer Portfolio

Production-ready, highly responsive portfolio website for Parth Patel, Full Stack Developer with 2+ years of production experience in Laravel, PHP 8.3, MySQL, and modern JavaScript.

## Features
- 🚀 **Interactive 3D Tech Stack Ecosystem**: Dynamic floating cards representing core technologies.
- 📬 **Dynamic Proposal Form**: Directly dispatches project proposals to `patelparth5133@gmail.com`.
- 🌓 **Theme Switcher**: Dark/Light mode toggle with system persistence.
- 💻 **Interactive Developer Terminal**: Embedded CLI console for quick commands.
- ⚡ **Lightning Fast & Optimized**: 60fps smooth animations, responsive mobile design, and high-performance assets.

## Quick Start

### Prerequisites
- Node.js (v18+)

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:3000`.

### 3. Build for Production
```bash
npm run build
```
